Private vs Public IP Address
Private IP Address
Used inside a local network (LAN).

Cannot be accessed directly from the internet.

Example:

192.168.1.10
10.0.0.5
172.16.1.20
Example
Laptop
↓
Router
↓
Mobile

Your laptop may have:

192.168.0.101

This is a private IP.

Public IP Address
Used on the internet and is globally unique.

Assigned by:

ISP
Mobile Operator

Example:

49.xxx.xxx.xxx
117.xxx.xxx.xxx
Example

When you visit Google:

Your Device
↓
Public IP
↓
Internet
↓
Google
Easy Analogy
Private IP

🏠 Room number inside a house

Example:

Room 101
Room 102

Only meaningful inside that house.

Public IP

🏠 House address

Anyone on the outside can find it.

Quick Difference
Private IP Public IP
Used inside LAN Used on Internet
Not globally unique Globally unique
Assigned by router Assigned by ISP
Example: 192.168.x.x Example: 49.x.x.x
