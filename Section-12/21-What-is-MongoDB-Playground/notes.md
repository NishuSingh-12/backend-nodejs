What is MongoDB Playground?

MongoDB Playground is a feature in VS Code that allows you to write and execute MongoDB queries in a .mongodb.js file.
It provides a convenient way to interact with MongoDB without opening the Mongo Shell.
Example
use("collegeDB");

db.students.find();

You can run the query directly from VS Code.

Benefits
Write and test MongoDB queries.
Execute multiple commands in one file.
No need to open mongosh separately.
