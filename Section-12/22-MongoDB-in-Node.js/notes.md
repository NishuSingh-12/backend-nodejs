MongoDB in Node.js
MongoDB in Node.js means connecting a Node.js application to a MongoDB database.
This allows Node.js to perform CRUD operations (Create, Read, Update, Delete) on MongoDB.
Install MongoDB Driver
npm install mongodb
Connect to MongoDB
const { MongoClient } = require("mongodb");

const client = new MongoClient("mongodb://localhost:27017");
Why Use MongoDB with Node.js?
Both work well with JSON-like data.
Easy database integration.
Used to store and retrieve application data.
