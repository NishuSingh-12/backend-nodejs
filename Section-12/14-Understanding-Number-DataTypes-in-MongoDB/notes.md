Understanding Number Data Types in MongoDB
MongoDB uses Number data types to store numeric values.
Numbers can be integers or decimal values.
Examples
{
"age": 22,
"price": 99.99
}
Common Number Types
Int32 → 32-bit integer
Int64 (Long) → 64-bit integer
Double → Decimal/Floating-point number

Quick Revision
Int32 → Integer Number
Int64 → Large Integer Number
Double → Decimal Number

Examples:
22 → Integer
99.99 → Decimal

Keyword: Int32, Int64, Double = Numeric Data Types ✅
