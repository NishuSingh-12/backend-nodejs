Story of World Wide Web

=> Before WWW internet already existed but it was difficult to use People mainly used:

-> commands
-> file transfers
-> text-based systems

=> Then in 1989 Tim Berners-Lee created World Wide Web (WWW) to make the internet easy for everyone

He introduced:
-> Websites
-> URLs
-> HTTP
-> Web Browsers
-> HTML

Goal
=> access and share information easily through clickable web pages.

Simple Flow
Browser
↓
HTTP Request
↓
Web Server
↓
HTML Response
↓
Website Displayed

Important Difference Internet ≠ WWW
=> Internet: global network infrastructure
=> WWW: websites running on the internet
