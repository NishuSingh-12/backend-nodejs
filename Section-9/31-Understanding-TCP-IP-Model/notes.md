Understanding TCP/IP Model
What is TCP/IP?
TCP/IP = Transmission Control Protocol / Internet Protocol

It is the practical networking model used on the Internet.

Layers of TCP/IP Model 4. Application 3. Transport 2. Internet

1. Network Access
   Layer 4 - Application Layer
   Provides services directly to applications.

Protocols:

HTTP
HTTPS
DNS
SMTP
FTP

Example:

Opening google.com
Layer 3 - Transport Layer
Provides end-to-end communication.

Protocols:

TCP
UDP

Uses:

Port Numbers

Examples:

80
443
4000
Layer 2 - Internet Layer
Responsible for routing packets between networks.

Uses:

IPv4
IPv6

Device:

Router
Layer 1 - Network Access Layer
Handles communication on the local network and physical transmission.

Uses:

MAC Addresses
Ethernet
WiFi

Devices:

Switch
Network Card (NIC)

Why TCP/IP is Important?
The Internet runs on TCP/IP.

Almost everything you use:

Websites
Mobile Apps
APIs
Email

works using TCP/IP protocols.
