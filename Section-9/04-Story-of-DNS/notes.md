Story of DNS(Domain Name System)
=> Earlier, people accessed websites using IP addresses

Example: 142.250.182.14

=> But humans cannot easily remember IP addresses So DNS was created.

Purpose
DNS converts domain names → IP addresses

Example:
google.com
↓
142.250.xxx.xxx

Why?
=> Because computers communicate using IP addresses but humans prefer easy names.

Simple Flow
Browser
↓
DNS Server
↓
Find IP Address
↓
Connect to Website
Real-World Analogy

=> DNS is like your phone contacts list You remember "Mom" instead of phone number
