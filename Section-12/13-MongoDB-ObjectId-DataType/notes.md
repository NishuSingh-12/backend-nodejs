MongoDB ObjectId Data Type
ObjectId is a special data type used to uniquely identify each document in MongoDB.
Every document automatically gets an \_id field of type ObjectId if you don't provide one.
Example
{
"\_id": ObjectId("6874abcd1234ef5678901234"),
"name": "Nishu"
}
Characteristics
Unique for every document.
Automatically generated by MongoDB.
12-byte value represented as a 24-character hexadecimal string.
