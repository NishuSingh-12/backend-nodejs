Dynamic IP Address
An IP address that changes automatically.

Assigned by:

Router
ISP

Example:

Today:

192.168.1.10

Tomorrow:

192.168.1.25

😄 IP can change.

Static IP Address
An IP address that remains fixed.

Example:

192.168.1.10

Always stays the same.

Real Examples
Dynamic IP
Home WiFi
Mobile hotspot
Mobile internet

Mostly dynamic.

Static IP
Company servers
Web servers
Database servers

Mostly static.

Why Static IP?

Because clients must always know:

where the server is located
Easy Analogy
Dynamic Address

🏠 House number changes every day.

Hard to find.

Static Address

🏠 House number never changes.

Easy to find.
