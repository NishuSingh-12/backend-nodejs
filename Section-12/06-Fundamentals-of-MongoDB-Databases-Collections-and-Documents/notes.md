Fundamentals of MongoDB: Databases, Collections, and Documents
Database
A Database is a container that holds collections.
Example: collegeDB
Collection
A Collection is a group of related documents.
Similar to a table in SQL.
Example: students
Document
A Document is a single record stored in a collection.
Stored in JSON-like format (BSON).
Example:
{
"name": "Nishu",
"age": 22
}
Structure
Database
└── Collection
└── Document

Quick Revision
Database → Collection → Document

Database → Container
Collection → Group of Documents
Document → Single Record

Collection ≈ Table (SQL)
Document ≈ Row (SQL)

Keyword: Database → Collection → Document ✅
