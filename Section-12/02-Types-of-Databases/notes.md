Types of Databases

1. Hierarchical Database
   Stores data in a tree structure.
   Uses Parent → Child relationship.
   One child can have only one parent.

Example: IBM IMS

Keyword: Tree Structure

2. Network Database
   Stores data in a network structure.
   A child can have multiple parents.
   Supports Many-to-Many relationships.

Example: IDS

Keyword: Multiple Parents

3. Relational Database (RDBMS)
   Stores data in tables (rows and columns).
   Uses SQL for data operations.
   Most commonly used database type.

Examples: MySQL, PostgreSQL, Oracle, SQL Server

Keyword: Tables + SQL

4. Object-Oriented Database (OODBMS)
   Stores data as objects.
   Follows Object-Oriented Programming (OOP) concepts.

Examples: ObjectDB, db4o

Keyword: Objects

5. NoSQL Database
   Stores data in a flexible format.
   Suitable for large-scale and unstructured data.
   Highly scalable.

Examples: MongoDB, Redis, Cassandra, Neo4j

Keyword: Flexible & Scalable

Interview Answers
What is a Hierarchical Database?

A Hierarchical Database stores data in a tree-like structure where each child has only one parent.

What is a Network Database?

A Network Database stores data in a network structure where a child can have multiple parents.

What is a Relational Database?

A Relational Database stores data in tables consisting of rows and columns and uses SQL for managing data.

What is an Object-Oriented Database?

An Object-Oriented Database stores data as objects and follows OOP principles.

What is a NoSQL Database?

A NoSQL Database stores data in a flexible format and is designed for scalability and large amounts of unstructured data.
