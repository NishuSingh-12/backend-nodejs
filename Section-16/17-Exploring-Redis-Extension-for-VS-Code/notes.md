# Exploring Redis Extension for VS Code

### What is Redis Extension?

- The **Redis extension for VS Code** allows you to work with Redis directly from VS Code.
- It helps you **connect to Redis, view keys, inspect values, and run Redis commands** without switching to a separate GUI.

### Main Features

- 🔌 Connect to a Redis server
- 🔑 Browse Redis keys
- 👀 View key values and data types
- 💻 Run Redis commands
- 🗄️ Manage Redis databases

### Basic Workflow

```text
VS Code
   ↓
Redis Extension
   ↓
Redis Server
   ↓
Keys & Values
```

### Example Redis Command

```bash
SET user:101 "Nishu"
```

Then you can view:

```text
user:101 → "Nishu"
```
