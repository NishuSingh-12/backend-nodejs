# 🔐 Using Inline Scripts with Nonce

### 📌 What is a CSP Nonce?

A **nonce (number used once)** is a **random, unpredictable value** that allows a specific inline script to execute under a Content Security Policy (CSP).

Instead of allowing all inline scripts with `'unsafe-inline'`, CSP allows only scripts containing the **correct nonce**.

---

### 🔹 How It Works

**Server generates nonce → Adds nonce to CSP → Adds same nonce to trusted script → Browser verifies → Script executes**

Example CSP:

```http
Content-Security-Policy: script-src 'self' 'nonce-abc123';
```

Trusted inline script:

```html
<script nonce="abc123">
  console.log("Hello");
</script>
```

- ✅ Correct nonce → Script executes
- ❌ Missing/wrong nonce → Script is blocked

---

### 🔹 Why Use Nonce?

Instead of:

```http
script-src 'self' 'unsafe-inline'
```

which allows **all inline scripts**, use:

```http
script-src 'self' 'nonce-<random-value>'
```

This allows only inline scripts with the valid nonce.

---

### ⚠️ Important Rules

- Nonce should be **random and unpredictable**.
- Generate a **new nonce for each HTTP response**.
- Never use a fixed or predictable nonce.
- The nonce must be kept secret from attackers who could inject content.

### 🧠 Nonce vs Hash

| Nonce                           | Hash                          |
| ------------------------------- | ----------------------------- |
| Random value                    | Hash of script content        |
| Usually generated per response  | Based on exact script content |
| Added to `<script>`             | No script attribute required  |
| Good for dynamic inline scripts | Good for fixed inline scripts |

### 🧠 Remember

> **CSP Nonce = A random token that gives permission to specific inline scripts.**

### 🎤 Interview Point

**Q: What is a nonce in CSP?**

**A:** A nonce is a random, unpredictable value generated by the server and included both in the CSP policy and trusted inline `<script>` elements. The browser executes only scripts with the matching nonce.
