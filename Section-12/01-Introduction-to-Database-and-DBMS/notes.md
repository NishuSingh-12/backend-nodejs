Introduction to Database and DBMS

1. What is a Database?

A Database is an organized collection of data that can be stored, managed, and accessed efficiently.

It helps in storing large amounts of information in a structured way so that data can be easily retrieved, updated, and deleted when needed.

Examples
Student records in a school
Customer details in an e-commerce website
Employee information in a company
Bank account details
Real-Life Example

Imagine a notebook where you store:

Roll No Name Marks
101 Nishu 85
102 Ravi 90
103 Priya 88

This notebook acts like a simple database because it stores information in an organized manner.

2. What is DBMS?

DBMS (Database Management System) is software that allows users to create, manage, and interact with databases.

Instead of directly handling files, users communicate with the DBMS, and the DBMS manages the data.

Definition

A Database Management System (DBMS) is software used to create, store, retrieve, update, and manage data in a database.

Examples of DBMS
MySQL
PostgreSQL
Oracle Database
Microsoft SQL Server
SQLite
MongoDB (NoSQL Database) 3. Why Do We Need a DBMS?

Before DBMS, data was stored in files.

Problems with File Systems
Data Redundancy (Duplicate Data)
Data Inconsistency
Difficult Data Retrieval
Poor Security
No Backup and Recovery
Data Isolation
Example

Suppose a student's phone number is stored in multiple files.

If the number changes and only one file is updated, different files will contain different phone numbers.

This creates data inconsistency.

DBMS solves this problem by maintaining a centralized database.

4. Components of DBMS
1. Database

Collection of related data.

2. DBMS Software

Software used to manage the database.

3. Users

People who interact with the database.

4. Applications

Programs that use the database.

Example:

Amazon Website
Banking App
Hospital Management System 5. Functions of DBMS
Data Storage

Stores data efficiently.

Data Retrieval

Fetches required data quickly.

Data Update

Allows modification of existing data.

Data Deletion

Removes unnecessary data.

Security

Protects data from unauthorized access.

Backup and Recovery

Recovers data if the system crashes.

Concurrency Control

Allows multiple users to access data simultaneously.

6. Advantages of DBMS
1. Reduced Data Redundancy

Duplicate data is minimized.

2. Improved Data Consistency

Data remains accurate and uniform.

3. Better Security

Access permissions can be assigned.

4. Easy Data Sharing

Multiple users can access data.

5. Backup and Recovery

Data can be restored after failures.

6. Data Integrity

Ensures data remains correct and valid.

7. Efficient Data Access

Data can be searched quickly.

7. Disadvantages of DBMS
   High Cost

Some DBMS software is expensive.

Complexity

Requires knowledge to manage.

Large Size

Needs more storage and memory.

Maintenance Cost

Regular maintenance is required.
