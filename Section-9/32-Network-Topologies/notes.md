Network Topologies
What is a Network Topology?
Network Topology = The physical or logical arrangement of devices in a network.

It describes how devices are connected to each other.

1. Bus Topology
   PC ─ PC ─ PC ─ PC
   ✅ Advantages
   Simple
   Low cost
   ❌ Disadvantages
   If the main cable fails, the whole network fails
   Difficult troubleshooting
2. Star Topology
   PC
   |
   PC ─ Switch ─ PC
   |
   PC
   ✅ Advantages
   Easy to manage
   Failure of one device doesn't affect others
   ❌ Disadvantages
   If the central switch/router fails, the entire network stops
   Example
   Home WiFi
   Office networks
3. Ring Topology
   PC ─ PC
   | |
   PC ─ PC
   ✅ Advantages
   Predictable data flow
   ❌ Disadvantages
   Failure of one node can affect the whole ring
4. Mesh Topology
   PC ─── PC
   |\ /|
   | \ / |
   | \/ |
   | /\ |
   | / \ |
   |/ \|
   PC ─── PC
   ✅ Advantages
   Very reliable
   Multiple paths available
   ❌ Disadvantages
   Expensive
   Complex wiring
   Example
   Internet backbone
   Enterprise networks
5. Tree Topology
   Router
   |
   Switch
   / \
    PC PC
   ✅ Advantages
   Easy to expand
   Good for large organizations
   ❌ Disadvantages
   Dependence on upper-level devices
6. Hybrid Topology
   Combination of multiple topologies

Example:

Star + Mesh
Star + Bus

Large corporate networks
