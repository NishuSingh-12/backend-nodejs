Read Operation in MongoDB
Read Operation is used to retrieve (fetch) data from a collection.
MongoDB uses the find() and findOne() methods to read documents.
Read All Documents
db.students.find()
Read One Document
db.students.findOne()
Read Documents with Condition
db.students.find({ age: 22 })

Quick Revision
Read Operation → Fetch Data

find() → Fetch Multiple Documents
findOne() → Fetch One Document
find({}) → Fetch Matching Documents

Keyword: Read = Retrieve / Fetch Documents ✅
