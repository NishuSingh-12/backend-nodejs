Delete Operation in MongoDB
Delete Operation is used to remove documents from a collection.
MongoDB provides deleteOne() and deleteMany() methods.
Delete One Document
db.students.deleteOne({ name: "Nishu" })
Delete Multiple Documents
db.students.deleteMany({ age: 22 })

Quick Revision
Delete Operation → Remove Data

deleteOne() → Delete One Document
deleteMany() → Delete Multiple Documents

Keyword: Delete = Remove Documents ✅
